# Ugadi 2026 - Telugu New Year Festival Website

A vibrant, responsive, and interactive website built to celebrate the Ugadi 2026 festival. This project features a traditional Telugu theme with a modern UI/UX, designed for community engagement and event management.

## 🌟 Features

- **Traditional Aesthetic**: Custom color palette (Saffron, Maroon, Gold, Ugadi Green) and cultural motifs.
- **Interactive Easter Eggs**:
  - **Falling Coconut Tree**: Click the tree on the homepage to drop coconuts!
  - **Ugadi Pacchadi Guide**: Interactive UI explaining the significance of the six tastes.
- **Event Management**:
  - **Ugadi Feast**: 3-step registration and UPI payment flow for food coupons.
  - **Culturals**: Detailed schedule for stage performances.
  - **Sports Meet**: Tournament registration for Cricket, Volleyball, Throwball, Badminton, and Indoor games.
- **Responsive Design**: Fully optimized for Mobile, Tablet, and Desktop screens.
- **Built with Modern Tech**: Next.js 15, TypeScript, Tailwind CSS 4, and Framer Motion.

## 🚀 Getting Started

### Prerequisites

- **Node.js**: v18.17.0 or later (Recommended: v20+)
- **npm**: v9+

### Installation

1. Clone the repository (if applicable) or navigate to the project folder.
2. Install the dependencies:

```bash
npm install
```

### Running the Project

To start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Building for Production

To create an optimized production build:

```bash
npm run build
npm run start
```
